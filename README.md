# Next.js Todo App 🚀

Školní projekt vytvořený v rámci cvičení z PV. Aplikace slouží jako Todolist s ukládáním dat do souboru.

## 🛠 Použité technologie
* **Next.js** (Pages Router)
* **TypeScript**
* **Tailwind CSS** (v3)
* **Node.js API** (Backend)

## ✨ Funkce
* ✅ **Přidání úkolu** (POST)
* 🗑 **Smazání úkolu** (DELETE)
* 🔄 **Splnění úkolu** (PUT - přepínání stavu)
* 💾 **Ukládání dat** (Persistence do JSON souboru)
* 🎨 **Dark Mode** design

## 🚀 Jak spustit projekt
1.  Nainstalovat závislosti:
    ```bash
    npm install
    ```
2.  Spustit server:
    ```bash
    npm run dev
    ```
3.  Aplikace běží na: [http://localhost:3000/tasks](http://localhost:3000/tasks)
